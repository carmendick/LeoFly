# LeoFly

LeoFly is a modern, modular flyer rendering engine built with Python.

It is designed to generate professional, high-quality flyers through reusable templates, themes, and structured data instead of manual graphic design.

## Project Status

🚧 LeoFly is currently under active development.

Current Version: **0.1.0 (Planning & Foundation)**

## Goals

- Build a reusable flyer rendering engine.
- Support multiple flyer templates.
- Support customizable themes.
- Generate high-quality PNG output.
- Provide a simple Command Line Interface (CLI).
- Serve as a clean, open-source Python project for learning and contribution.
